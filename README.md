# Shir Kanevsky

Personal author website built with Next.js, TypeScript, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Structure

- `src/app` - routes and global styles
- `src/components` - shared layout and UI components
- `src/config` - navigation and site-wide details

Update the temporary email address in `src/config/site.ts`. Image placeholders are intentionally implemented as components and can be replaced with project photography later.
